I'm currently at **Mettler Toledo** building GenAI tools, Python automations, and web applications that connect to enterprise systems and replace workflows that shouldn't be manual anymore.

Before this, I spent two years in Canada studying Cloud Computing and Data Analysis at Durham College, tutoring students, and working at a Toronto AI startup where I shipped an NLP/ML feature into production on an AWS Kubernetes cluster.

> **Core Directive:** I care about the full pipeline — clean data, a model that actually works, and a deployed application that people can use.
